<h2><a href="https://www.geeksforgeeks.org/problems/sort-a-stack/1">Sort a Stack</a></h2><h3>Medium</h3><hr><p>Given a stack of integers <code>st[]</code>. Sort the stack in ascending order, such that the smallest element is at the bottom and the largest element is at the top.</p>

<p>You are required to sort the stack without using any sorting algorithm. The stack should be sorted using stack operations.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong> st[] = [41, 3, 32, 2, 11]

<strong>Output:</strong> [41, 32, 11, 3, 2]

<strong>Explanation:</strong> After sorting, the smallest element (2) is at the bottom
and the largest element (41) is at the top.
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre>
<strong>Input:</strong> st[] = [3, 2, 1]

<strong>Output:</strong> [3, 2, 1]

<strong>Explanation:</strong> The stack is already sorted in ascending order.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= st.size() &lt;= 10<sup>3</sup></code></li>
	<li><code>1 &lt;= st[i] &lt;= 10<sup>3</sup></code></li>
</ul>
